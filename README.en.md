# Quinta AI Gateway

Quinta AI Gateway is an enterprise AI Gateway and MaaS platform for multi-tenant AI API routing, provider access, channel management, billing, quota control, and tenant isolation.

## Positioning

- Multi-tenant data ownership and admin isolation
- Tenant, organization, department, and distribution-channel management foundation
- Model provider access and routing management
- Token usage metering and billing foundation
- Top-up, voucher, subscription, invoice, payment, and revenue-share foundations
- Tenant-scoped admin console and commercial dashboards

## Documentation

Project documentation lives in the `docs/` directory. Commercial UI and product rebranding notes are tracked under `docs/iteration_12_1/`.
