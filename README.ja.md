# Quinta AI Gateway

Quinta AI Gateway は、マルチテナントの AI API ルーティング、プロバイダー接続、チャネル管理、課金、クォータ制御、テナント分離に対応するエンタープライズ AI Gateway / MaaS プラットフォームです。

## 位置づけ

- マルチテナントのデータ所有権と管理画面の分離
- テナント、組織、部門、分配チャネル管理の基盤
- モデルプロバイダー接続とルーティング管理
- トークン使用量計測と課金基盤
- チャージ、バウチャー、サブスクリプション、請求書、決済、収益分配の基盤
- テナントスコープの管理コンソールと商用ダッシュボード
