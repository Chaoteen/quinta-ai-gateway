# 关于 Quinta AI Gateway

Quinta AI Gateway 是面向企业与开发者的 AI 模型接入和用量管理平台。我们希望让企业通过统一入口，为内部 Agent、业务系统和开发工具连接所需的模型资源，并集中管理访问权限、使用额度与费用记录。

## 连接 AI 接入与企业日常管理

企业可以按业务需要选择模型，为不同应用配置独立 API Key，并通过用量与账单记录了解资源消耗。个人开发者也可以注册账号，在获得可用额度及模型权限后开始接入。

平台以企业直接使用为主要服务场景，围绕模型 API 和企业 Agent 持续建设订阅、额度补充和商业运营流程。具体可用模型、价格和服务范围，以平台配置及双方约定为准。

## 我们关注的四件事

- **接入方便**：提供统一网关入口，减少业务系统对多家供应商分别集成的工作。
- **权限清晰**：按角色及访问范围管理后台操作，为应用配置独立密钥和访问限制。
- **费用可核对**：提供用量、账单与发票申请入口，便于日常管理和财务核对。
- **能力逐步落地**：围绕企业需求完善订阅、卡券、优惠和配套 Agent 服务，以实际可用功能交付。

[阅读 API 接入指南](__API_GUIDE_URL__)，了解如何创建密钥、查询模型和发送首次请求；或访问[模型广场](__MODELS_URL__)了解模型信息。

## 当前服务状态

当前站点为持续建设中的预览版本。供应商展示不代表所有模型均已上线；智能体市场、知识库、工作流等尚未交付的模块会标注为即将推出。真实在线收款和自动开票尚未启用，发票申请需由财务审核并按实际业务办理。预览展示不构成认证或服务等级保证。
