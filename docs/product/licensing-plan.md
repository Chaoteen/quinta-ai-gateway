# Quinta AI Gateway 许可实施方案

本方案记录当前公开版本的交付方式，不替代 LICENSE 或上游授权合同，不构成已购买商业授权的声明。

## 当前路线：AGPLv3 商业运营并提供对应源码

- 保留 new-api、QuantumNous 的原有版权、署名和许可，不更改上游 LICENSE。
- 修改版本清楚说明来源和二开关系，保留上游要求的可见署名及链接。
- 网站提供许可与源码入口，并尽可能指向实际部署版本的对应源码。
- 发布包保留 LICENSE、NOTICE、THIRD-PARTY-LICENSES.md、版本标识；可复现构建所需的业务源码、前端源码、依赖锁和构建脚本一并公开。密码、私钥、真实客户资料和生产环境文件不属于公开源码材料。
- 对源码请求、依赖许可和第三方 NOTICE 进行发布检查，不能用仓库 public 状态代替逐项履约。

## 未来闭源路线

若希望不向网络服务用户提供修改版本的对应源码，或客户合同要求专有授权，需与 QuantumNous 核实并取得覆盖目标版本、修改、部署、再分发和客户交付场景的书面授权。不能把 AGPL 改成 MIT/Apache，也不能认为拆分服务或重命名会自动消除义务。

当前没有商业授权合同。商标、模型供应商资源授权、支付与开票服务商合同分别处理；软件开源许可不等于模型资源转售许可。正式合同由有权主体和专业顾问确认。
