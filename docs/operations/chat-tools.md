# 用户配置聊天工具

侧栏的聊天工具是可选的第三方应用入口。内置“模型体验”使用登录会话，第三方工具通常需要客户自己的网关 API 密钥，两者不是同一种接入方式。

## 启用工具

1. 打开“配置聊天工具”，或进入“个人资料 → 聊天工具”。
2. 点击具体工具旁的“配置连接”。在窗口里点击“创建专用密钥并启用”，或选择已有网关密钥后点击“绑定所选密钥并启用”。不必先跳转到其他页面，也不要填写上游供应商的 Key。
3. 绑定后点击“导入到对应工具”，系统会传入连接信息，无需用户填写地址。配置弹窗不展示 API 地址，也不重复显示掩码密钥。需要手动连接时，点击“手动接入说明”查看 API 文档，密钥可在“API 密钥”控制台复制。
4. 回到聊天菜单，只会看到已经启用的工具。关闭开关后，对应入口立即隐藏。未配置偏好的账号默认不启用任何第三方工具。

开关只保存菜单偏好，不会安装客户端、创建 API 密钥或增加余额。关闭工具不会撤销此前已经导入客户端的密钥；如需撤销访问，请在“API 密钥”中禁用或删除对应密钥。

专用密钥只有在用户明确点击创建按钮时才会创建，默认有效30天、有限额度，上限为创建时的账户余额。重复点击会复用该工具已经绑定的有效密钥，不会重复创建。创建不会增加余额或产生支付订单。可以在“API 密钥”控制台调整限额、过期时间和模型限制；列表会显示每把密钥关联的工具。

每个工具独立保存绑定的密钥 ID，可以分别使用不同密钥。启动时严格读取所绑定的密钥，失效时要求重新配置，不自动改用其他密钥。偏好中不保存明文密钥，创建和绑定接口也不返回明文；只有明确复制或导入时才通过原有密钥读取接口取得明文。

平台生成的客户密钥可以用于 Cherry Studio：客户端把它作为本平台模型服务的 Bearer 凭据，而不是作为 Cherry Studio 登录凭据。Cherry Studio 官方提供 New API 服务商类型；导入数据使用 `id=new-api`、平台根地址和客户密钥。根地址保留 `/quinta`，客户端再追加协议版本路径。参见[官方 New API 接入说明](https://www.cherryai.com.cn/docs/zh-cn/pre-basic/providers/newapi/)。

“平台连接配置已保存”只代表平台端的密钥绑定已完成，不宣称本机客户端已安装、已接受协议唤起或已完成模型检测。启动后仍需在客户端确认导入并选择可用模型。

## 桌面工具和网页工具

- Cherry Studio、AionUI、DeepChat 等通过应用协议启动本机客户端，需要事先安装客户端并允许浏览器打开。它们不是服务器上已经部署好的网页聊天窗口。
- CC Switch 使用专用的导入配置窗口，先选择应用和模型，再通过 `ccswitch://v1/import` 协议打开客户端；不能将旧配置中的 `ccswitch` 占位值作为网页地址访问。
- 网页工具是第三方网页，可能受登录、网络或其嵌入策略限制。启用工具不保证第三方网站始终可用。

导入连接会将客户的网关 API 密钥交给选择的应用。平台不会自动创建密钥，也不会自动把上游 Key 传给这些工具。首次配置时应确认所选应用可信，建议为不同客户端分别创建限额密钥。

## 管理员维护

平台的 Chats 配置定义可供选择的工具；个人的 `enabled_chat_apps` 只保存工具名称。个人偏好通过 `PUT /api/user/self/chat-preferences` 更新，不接受客户指定其他用户，且只更新该设置项，保留通知、语言等其他设置。

`POST /api/user/self/chat-key` 在事务中完成创建／绑定与启用，`chat_key_bindings` 记录工具名称和密钥 ID。已有密钥必须属于当前用户和租户，并处于可用状态。新建操作沿用密钥数量上限、加密随机密钥生成和账户额度约束，不接受用户指定其他账号。

网页链接须使用 HTTPS；桌面链接仅支持已知应用协议。无效的相对路径或脚本链接不会显示在配置列表。过滤菜单后仍使用原始工具 ID 查找网页配置，避免启用部分工具时打开其他工具。

验证覆盖用户设置隔离、其他设置保留、关闭所有工具、页面刷新、密钥前置检查、未启用工具隐藏，以及 CC Switch 导入协议和 `/quinta/v1` 路径。
