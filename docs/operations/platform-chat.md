# 站内在线聊天（内测）

主菜单“在线聊天”使用 `/playground` 路由和现有 `/pg/chat/completions`，在本平台流式回答，不做 SSO/OAuth，不唤起外部客户端。Cherry Studio 等连接仍可在个人设置中按需配置。

每次发送前，认证后的 `/api/user/self/assistant/context` 根据当前问题检索编译嵌入的公开用户文档，按关键词相关度选择最多三篇；不是向量检索，也没有读取企业私有文档。公开目录由 `docs/user-guide/embed.go` 显式列出，不接受任意文件路径。文档单篇限3200字符，其他运维、安全和内部文档不进入知识库。参考资料随回答展示，公开文档页渲染同一份Markdown。

联网默认关闭；主动开启后只将当前问题的前256个字符作为查询，服务端请求固定 `https://www.bing.com/search?format=rss`，使用最多5条公开网页摘要，不主动抓取来源页面。拒绝明显凭据查询；界面仍提醒用户不要输入秘密/隐私信息。10秒超时、256KiB响应限制、拒绝HTTP重定向、过滤危险/本地/带凭据链接。每账号每分钟最多20次检索。搜索失败返回503，不静默声称联网成功；空结果显示提示。来源内容是非可信数据，不提供任何修改账户或资金的工具。

这是尽力服务的内测RSS适配，未取得生产搜索SLA；搜索结果可能不相关，不能保证全面性与时效性。商业正式上线前应接入签约的搜索API，完成隐私条款、检索质量及服务可用性评估。不使用当前Qwen渠道的 `enable_search` 成功响应作为联网凭证。

检索上下文放入该次模型输入，因此正常计入模型Token费用；充值/额度限制与计费仍走原网关，不创建外部API密钥、不改变余额。对话仅按用户ID保存在当前浏览器，不是服务器云端历史；旧版无账号归属的本地历史不自动迁入新账号。共享电脑退出后应清理站点数据。
