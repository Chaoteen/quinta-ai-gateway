# 管理员认证器绑定与恢复准备

管理员安全页 `/security-center` 仅供平台最高管理员查看，检查启用中的管理账号是否有TOTP或未标记克隆告警的Passkey绑定记录。不读取认证器种子、密钥、公钥或恢复码。记录存在不等于认证已成功演练；检查失败或结果截断不能判定就绪。

用户配合：使用最高管理员账号进入个人资料，扫描两步验证二维码并输入验证码确认；把恢复码保存到密码管理器或离线安全介质，和手机、ECS分开。不得把二维码、种子、动态验证码或恢复码发给研发、客服或提交仓库。

保持当前可用会话，另开无痕窗口验证密码加认证器登录，再验证供应商管理访问。强制启用前应测试一枚恢复码并记录其已消费；重新生成后旧码失效，应安全替换副本。恢复码使用不能标记为仍可备用。

当前站点使用IP，先采用TOTP；Passkey另需核对正式域名、HTTPS和WebAuthn RP配置。用户还需确保能安全登录自己的云控制台，并与可信运维确认独立的服务器维护通道。不需要在聊天里交出云账号密码或SSH私钥。

全局强制MFA和维护恢复操作尚未由此页面实现或开启。只有绑定记录齐备、独立登录及恢复演练通过、维护身份核验及审计方案明确后，才进入强制策略发布。页面不提供免认证恢复接口，不自动关闭任何认证器，不替生产管理员保管恢复码。

密码通过后的认证器/恢复码验证须在五分钟内完成；超时或升级前留下的旧挑战需要重新输入密码。恢复码一次性使用，多个请求同时提交同一恢复码仅一个可成功。完成登录后原先的敏感操作二次验证授权会清除，进行敏感操作时可能需要再次验证。

已启用TOTP的账号，改用第三方OAuth或Passkey登录后也须完成本平台的认证器/恢复码验证。这是账号已开启的两步验证要求，不表示所有未绑定账号都已被强制开启MFA。第三方账号绑定与登录不同，绑定操作不会代替管理员认证器设置。
