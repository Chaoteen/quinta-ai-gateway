# 账号与 API Key

账号用于登录 Quinta AI Gateway 控制台，API Key 用于应用调用网关接口。

## 账号

账号通常由管理员创建或邀请。不同角色可看到不同菜单和数据范围：

- 普通用户：管理自己的 API Key、额度和使用记录。
- 租户管理员：管理租户内用户、渠道、订阅、账单和企业设置。
- 财务或运营角色：按权限查看计费、发票、支付和日志。

## API Key

API Key 是应用访问网关的凭证。创建后请立即保存，避免泄露。

建议：

- 不要将 API Key 写入前端代码。
- 不要提交到 Git 仓库。
- 为不同应用创建不同 API Key。
- 定期轮换长期使用的密钥。
- 发现泄露后立即禁用或删除。

## 权限与额度

API Key 的可用模型、额度和请求限制受账号、租户、订阅和管理员配置影响。如果请求失败，请先检查账号状态、额度余额和模型权限。

## 审计

管理员可通过使用日志查看 API Key 的调用情况，包括请求时间、模型、Token 消耗和计费状态。
