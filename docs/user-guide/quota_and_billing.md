# 额度与计费

Quinta AI Gateway 使用额度和计费记录来追踪模型调用成本、租户消费和账户余额。

## 额度

额度表示当前账号或租户可用于模型请求的资源。额度可能来自：

- 充值或管理员分配。
- 订阅计划。
- 卡券兑换。
- 运营活动或人工调整。

## 用量

每次模型请求会记录请求量、输入 Token、输出 Token、总 Token、模型和供应商。不同模型可能使用不同计费倍率。

## 账单

账单中心展示消费汇总、最近账单和模型消费排行。账单记录用于核对模型请求是否已完成计费。

## 冻结与扣减

部分请求可能会先冻结额度，再根据实际用量结算。若请求失败，系统应释放或返还未使用的额度。

## 对账建议

- 定期检查额度余额和账单记录。
- 使用请求 ID 对齐使用日志和账单。
- 对异常消费及时联系管理员。
