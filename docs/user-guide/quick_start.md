# 快速开始

本文面向首次使用 Quinta AI Gateway 的用户，帮助你完成从登录到第一次 API 请求的基础流程。

## 1. 登录平台

打开 Quinta AI Gateway 访问地址，可以自行注册普通账号并登录，注册成功后自动启用，初始余额为0。企业账户及权限由平台协助开通。如果你的环境启用了邮箱、OAuth 或 Passkey，请按页面提示完成认证。

## 2. 查看控制台

登录后进入控制台，重点确认：

- 当前账号状态正常。
- 所属租户、组织或角色正确。
- 可用额度或订阅权益满足测试请求。
- 管理员已配置至少一个可用模型渠道。

## 3. 创建 API Key

进入 API Key 页面，创建用于应用调用的密钥。请妥善保存密钥明文，避免提交到代码仓库或公开日志。

## 4. 发起第一次请求

使用兼容 OpenAI 的客户端或 HTTP 工具，将 Base URL 指向 Quinta AI Gateway 的网关地址，并在请求头中携带 API Key。

## 5. 查看用量

请求完成后，可在使用日志、额度与用量、账单中心查看请求状态、Token 消耗和计费记录。

## 下一步

- 阅读 `docs/user-guide/api_access.md` 完成正式接入。
- 阅读 `docs/user-guide/quota_and_billing.md` 理解额度和计费。

## 站内在线聊天

点击菜单“在线聊天”即可在本平台对话，不会唤起 Cherry Studio 等客户端。选择账号可用模型后，提问平台接入、计费、卡券或发票问题，系统会检索公开功能文档并展示参考资料。开启“联网检索”时，当前问题（最多256字）发送给 Bing 检索公开网页摘要，再由模型结合资料回答；请勿包含密钥或隐私信息。搜索失败会提示，可重试或关闭联网。

本轮对话会按账号保存在当前浏览器，不是跨设备云端会话；共享电脑使用后应退出账号并清理浏览器站点数据。检索不意味着后台操作，聊天不会替用户充值、开票、退款或改变权限。模型回答及检索文档的输入会消耗账号模型额度。
