# 常见问题

## 为什么请求返回 401？

通常是 API Key 缺失、格式错误、已删除或已禁用。请重新创建或检查请求头。

## 为什么请求返回 403？

当前账号、API Key、租户或角色没有访问目标资源的权限。请联系管理员确认模型权限和角色配置。

## 为什么额度足够但请求失败？

可能是模型渠道不可用、上游服务异常、触发限流或订阅权益不匹配。请查看使用日志中的错误信息。

## 如何查看 Token 消耗？

进入使用日志或额度与用量页面，查看请求量、输入 Token、输出 Token 和总 Token。

## 如何申请发票？

在发票管理页面提交开票信息，并关联对应支付订单或账单记录。财务审核后会更新发票状态。

## 在线聊天与客户端接入有什么区别？

在线聊天在本平台网页内完成，通过当前账号调用已开通模型并消耗额度，不需要安装 Cherry Studio。支持检索平台公开功能文档；主动开启联网检索后，当前问题会发送给公开网页搜索服务，模型参考返回的网页摘要作答。搜索无结果或不可用时会明确提示，不能把模型记忆当作实时查询。

Cherry Studio 等是可选外部客户端，个人设置中的连接配置用于把本平台加入客户端的模型供应商列表，不是 SSO/OAuth 登录。平台 API Key 只用于本平台网关，不授予其他供应商权限。
