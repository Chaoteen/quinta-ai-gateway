# 常见问题

## 为什么请求返回 401？

通常是 API Key 缺失、格式错误、已删除或已禁用。请重新创建或检查请求头。

## 为什么请求返回 403？

当前账号、API Key、租户或角色没有访问目标资源的权限。请联系管理员确认模型权限和角色配置。

## 为什么额度足够但请求失败？

可能是模型渠道不可用、上游服务异常、触发限流或订阅权益不匹配。请查看使用日志中的错误信息。

## 如何查看 Token 消耗？

进入使用日志或额度与用量页面，查看请求量、输入 Token、输出 Token 和总 Token。

## 如何申请发票？

在发票管理页面提交开票信息，并关联对应支付订单或账单记录。财务审核后会更新发票状态。

## 文档页面为什么只显示目录？

当前 `/docs` 页面先提供静态目录。详细 Markdown 文档已放在 `docs/user-guide/` 下，后续可接入前端 Markdown 渲染或文档站构建流程。
