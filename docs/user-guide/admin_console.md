# 管理员控制台

管理员控制台用于租户或平台管理员管理用户、渠道、商业化能力和系统配置。

## 常用入口

- 用户管理：创建用户、分配角色、查看状态。
- 渠道管理：配置上游模型供应商和路由能力。
- 订阅管理：管理订阅计划和用户权益。
- 账单中心：查看消费、账单和模型排行。
- 卡券管理：创建和审计卡券。
- 发票管理：处理企业开票流程。
- 使用日志：排查请求、错误和计费状态。
- 额度与用量：查看额度余额和用量统计。
- 企业设置：维护租户基础配置。

## 权限边界

不同角色只能看到授权范围内的数据。租户管理员默认只能管理本租户数据，平台 root 账号保留全局管理能力。

## 操作建议

- 生产环境修改渠道前先测试连通性。
- 调整计费配置前记录变更原因。
- 定期导出或核对关键商业记录。
