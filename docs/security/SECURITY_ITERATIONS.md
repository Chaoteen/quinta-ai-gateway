# 近期安全迭代与验收边界

## 管理员认证重置权限补丁

管理接口不得解除操作者自己、同级/更高级账号或最高管理员角色账号的TOTP，与Passkey管理重置的限制保持一致；应使用账号自己的认证设置或经核验审计的维护恢复流程。Passkey重置使用返回真实数据库错误的用户读取方法，目标不存在或读取失败时不继续处理。隔离测试验证被拒绝操作后两种凭据仍保留。本补丁未实现管理员重置的近期二次验证交互、完整应急恢复或现有会话撤销，不修改生产凭据。

## 2026-11-16 本批应用改动

- 平台采购管理仅最高管理员可读，所有写入要求近期MFA二次验证；二次验证绑定当前账号，并拒绝未来时间戳；Passkey预验证标记一次性消费且绑定账号。
- 供应商账号只绑定已核验官方HTTPS源站及对应协议，拒绝私有/伪装域名、订阅路径和SDK路径误填。不将API Key明文复制到新采购模块。
- 绑定后的端点与协议发生变化时阻止后续调用；供应商暂停、账号暂停或授权到期后阻止新请求；禁止直接复制绑定渠道。
- 采购金额用精确十进制转换整数，报价与付款分离；付款流水幂等且累计不能超额；业务与审计在同一事务写入。
- 新表及渠道归属字段使用兼容迁移；本批不自动绑定旧渠道、不改变现有余额、不自动向上游转账。

P1：集中防篡改审计与告警、应用/数据库/备份权限隔离、依赖及镜像持续扫描、全租户越权回归、上传及出站请求的SSRF专项、支付回调和异步任务异常恢复。应用层审计表不能替代独立防篡改审计存储。

P2：等保定级边界、备案材料与制度、第三方测评及整改闭环。安全代理进程、WAF购买记录或代码扫描通过都不能单独证明达到等保二级。

本批测试以隔离SQLite和浏览器模拟接口为主；需继续验证MySQL/PostgreSQL/Redis多实例，以及五家官方真实账号的协议、配额、费用与授权范围。源代码公开不包含真实生产凭据；不以隐藏漏洞或隐藏署名代替修复和履行许可证。

## 2026-11-16 第二批：缓存一致性与采购关联保留

调用检查以数据库当前渠道及供应商关联为准，不能根据缓存中的supplier_account_id=0直接放行。新绑定、暂停、授权到期以及数据库中端点/协议变更，即使本实例仍持有旧渠道缓存，也必须检查最新状态；记录不存在、绑定不一致或查询失败时拒绝调用。当前实现每次检查读取数据库，后续性能优化不得丢失这个授权边界。

单条、批量、按状态和清理禁用渠道均通过同一事务删除流程：锁定候选渠道，检查渠道归属字段及实际供应商账号关联，只删除未绑定记录并同步清理abilities。涉及绑定渠道时整批拒绝，不删除其他选中渠道；保留合同、账单和付款关联。租户清理只影响本租户记录。

新增隔离测试覆盖旧未绑定缓存、新绑定后暂停/到期、数据库端点变更、四种删除入口的整批回滚，以及租户作用域。没有启动真实多节点Redis环境，不能把这些回归测试表述为已完成多机压力验收；未调整端口、管理员认证器或密钥。

## 2026-11-16 第三批：认证恢复与密码登录边界

恢复码使用改为数据库条件更新，只有成功把未使用记录标记为已使用的请求才能通过验证；并发重放不能重复成功。新增同步并发回归，确保多个请求已读取同一未使用恢复码后只有一个更新成功。使用GORM和参数化布尔值，不引入数据库专属语法；实测仍为隔离SQLite。

密码登录读取两步验证配置失败时返回失败，不能降级为无两步验证登录。密码验证后的待验证会话有效期为五分钟，拒绝缺少时间戳、未来时间戳及过期挑战；完成第二步前重新检查账号启用状态。新密码挑战清除旧会话身份和近期二次验证授权，登录完成也清除旧挑战及授权，防止跨登录继承。

本批未开启全局强制MFA，未改变生产管理员绑定或恢复码；旧的待验证挑战需要重新输入密码。第三方OAuth、Passkey、访问令牌与既有登录会话的统一强制策略仍需另行覆盖，不能据此宣称已实现所有认证入口的强制MFA或完整的会话撤销机制。

## 2026-11-17 第四批：交互登录统一两步验证

密码、统一OAuth、保留的旧OAuth/微信/Telegram入口和Passkey身份验证完成后统一经过setupLogin：重新读取当前用户状态和本地TOTP配置。账号已启用TOTP时只返回限时挑战，必须通过认证器或恢复码才可建立会话；第三方身份验证或Passkey成功本身不跳过账号已启用的TOTP。查询失败或账号已禁用时拒绝建立新会话。仅第二步验证完成可调用completeLogin，不重复保存中间会话Cookie。

默认前端补齐OAuth回调、微信与Passkey的挑战跳转，进入OTP前清除旧的本地用户和uid，避免把挑战响应当成用户资料。经典主题同步补齐对应跳转。绑定已有第三方账号的流程不当作登录挑战。

隔离测试覆盖真实Cookie往返、挑战阶段无登录身份、恢复码完成后建立身份、最新禁用状态和查询失败；默认前端浏览器模拟验证OAuth→恢复码→控制台闭环。两种前端构建通过。未用真实第三方OAuth账号或硬件Passkey做端到端验收；访问令牌、已有会话撤销与未绑定管理员的全局强制策略仍属后续工作。本批不启用全局强制MFA，不修改生产认证器绑定。

## 管理员重置近期二次验证

TOTP和Passkey管理重置接口均要求绑定当前账号的五分钟内安全验证记录；无记录、过期、未来时间戳或跨账号记录拒绝操作。默认和经典前端在确认重置后先打开验证弹窗，成功后执行原重置请求；取消验证不发送重置请求。未绑定验证方式的操作者需先绑定认证器或Passkey。原有自己/同级/最高管理员保护继续有效。此改动不提供绕过认证的恢复接口，不开启全局强制MFA。

## 认证器重置事务审计

新增CredentialResetAudit，本地审计只记录操作者ID、目标ID、目标租户、凭据类型和时间，不记录种子、恢复码、公钥或请求正文。管理员TOTP和Passkey重置将删除与审计写入放在同一业务数据库事务中；审计写入失败时回滚删除。事务锁定账号并重新检查操作者状态、权限、租户边界和受保护目标。TOTP重置同步删除备用码；Passkey沿用硬删除以允许重新注册。隔离SQLite测试覆盖审计失败回滚与成功留痕。未在生产执行凭据重置测试，未完成MySQL/PostgreSQL真实并发验收。现有普通日志仅为辅助展示，不作为事务审计替代。该表不是独立不可变存储，查询界面、外送防篡改存储、告警和会话撤销仍需后续实现。

## 认证器重置审计查询

最高管理员可在管理员安全页查看CredentialResetAudit，接口/platform/security/credential-resets使用正整数before游标，每页最多20条，按ID倒序；禁止非最高管理员读取，禁止缓存。不连接凭据表、不返回种子、恢复码或公钥，不提供删除入口。空记录与查询失败分别提示。这里只显示成功提交的管理重置；拒绝操作和其他认证事件尚未统一收集，独立告警和防篡改存储仍未完成。

## 认证重置后的浏览器会话撤销

管理员重置成功的同一事务递增目标账号auth_epoch；审计失败时版本同时回滚。浏览器会话保存登录时版本，认证中直接读取数据库最新版本，版本不符返回401，清除本次会话；避免缓存延迟导致旧Cookie继续访问。待完成的两步验证也绑定版本，防止旧挑战在重置后完成登录。新字段只读，普通用户资料Save不会覆盖版本；旧Cookie缺少版本按0处理，首次重置后失效。已经执行中的请求不被中断。个人访问令牌、API密钥、公开页面TryUserAuth及模型中转令牌不在本轮浏览器会话撤销范围，未实现管理员手动撤销按钮或密码修改统一撤销。每次浏览器认证增加一次数据库查询，性能和多数据库并发需要后续验收。

## 密码修改与找回后的浏览器会话撤销

用户Update/Edit的密码变更与auth_epoch递增放入同一事务，查询失败不继续更新；无密码变更的资料更新明确忽略password字段。邮箱找回密码用单条SQL原子更新密码和会话版本，零匹配返回失败。新密码提交后当前及其他旧浏览器会话在下次受保护请求时失效，需要重新登录；待验证挑战沿用版本校验。隔离测试覆盖三个入口的版本更新、注入版本写入错误时密码回滚、资料更新不改密码或版本。API密钥及个人访问令牌不在此撤销范围；密码找回验证码的并发消费和统一通知、独立防篡改审计仍需后续处理。本轮不修改生产密码或主动撤销生产会话。

## 出站、HTML与浏览器策略补强

生产环境HTTP Transport不再使用HTTP_PROXY/HTTPS_PROXY环境代理，防止代理绕过本地目的地址校验；WebSocket使用受控拨号器并禁用环境代理，沿用实际连接IP防回绑检查。测试覆盖元数据目的地址及代理策略；不代表所有SDK、自定义代理或远端Worker已通过全路径审计。

默认主题通用Markdown在rehype-raw之后使用rehype-sanitize默认白名单；浏览器测试覆盖脚本、onerror、iframe、表单及javascript链接清除，保留正常Markdown。未审计经典主题所有富文本渲染组件和自定义远程iframe的隔离边界。

保留基础强制CSP，同时默认提供包含script-src的完整Content-Security-Policy-Report-Only观察策略；SECURITY_CSP_ENFORCE=true才切换强制完整策略。报告只在浏览器可见，未配置服务器报告接收器；不得将观察模式表述为脚本拦截已生效。脚本允许同源及challenges.cloudflare.com，不含unsafe-inline或unsafe-eval。需在真实聊天、图表、验证码等路径验证后启用。

HSTS仅当SECURITY_HSTS_HOST与请求主机匹配且为非IP，并配置SECURITY_HSTS_MAX_AGE在300至31536000秒、HTTPS请求时输出；不带includeSubDomains/preload。生产IP站点未启用，不改变同机其他服务策略。正式域名和证书尚待确认。

独立审计待用户提供独立SLS/存储目的地与授权：应采用独立账号最小写权限、保留锁/不可变策略、访问隔离、批次确认与失败重试告警，并验证删除/篡改主机不能删除远端副本。本轮未接入远端审计，不以应用表、同机文件或本地备份替代。禁止将目的地写入凭据、真实Cookie、请求正文、模型密钥或恢复码。

## 经典富文本与远端Worker隔离

经典主题文档、公告、通知、FAQ及自定义页脚经过DOMPurify的HTML白名单清洗；去除脚本/事件、iframe/表单、style标签与style属性。文档不再向document.head注入用户内容中的CSS，只允许HTTP(S)外链。Mermaid改为strict安全等级。浏览器注入测试确认协议文档保留正常文本且恶意JS/全局CSS不执行。自定义页脚/文档的内联样式会被剥离，需使用平台样式；不是所有dangerouslySetInnerHTML调用均已完成审计。

生产环境禁止DoWorkerRequest远端代理请求，防止另一端DNS解析及连接绕过本地SSRF防护；不静默fallback。开发模式增加空请求、严格HTTP(S)协议、有效主机与禁止userinfo的校验。Worker下载日志地址脱敏，JSON通过common封装。若未来恢复Worker，必须验证远端DNS/连接IP、元数据与私网阻断、重定向、凭据转发和目的地授权，再提供独立受控连接器。
