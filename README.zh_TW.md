# Quinta AI Gateway

Quinta AI Gateway 是面向企業級 AI API 中轉、模型接入、渠道管理、計費結算和租戶隔離場景的多租戶 AI Gateway / MaaS 平台。

## 專案定位

- 多租戶資料歸屬與後台隔離
- 租戶、組織、部門、分銷渠道管理基礎
- 模型供應商接入與路由管理
- Token 用量記錄與計費基礎
- 充值、卡券、訂閱、發票、支付與收益分成基礎
- 租戶級管理後台與商業化儀表板
