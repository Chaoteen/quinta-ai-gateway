# Quinta AI Gateway

Quinta AI Gateway 是面向企业级 AI API 中转、模型接入、渠道管理、计费结算和租户隔离场景的多租户 AI Gateway / MaaS 平台。

## 项目定位

- 多租户数据归属与后台隔离
- 租户、组织、部门、分销渠道管理基础
- 模型供应商接入与路由管理
- Token 用量记录与计费基础
- 充值、卡券、订阅、发票、支付与收益分成基础
- 租户级管理后台与商业化仪表板
