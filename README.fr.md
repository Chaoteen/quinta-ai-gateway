# Quinta AI Gateway

Quinta AI Gateway est une plateforme Enterprise AI Gateway / MaaS pour le routage d API IA multi-tenant, l acces aux fournisseurs de modeles, la gestion des canaux, la facturation, les quotas et l isolation des tenants.

## Positionnement

- Propriete des donnees multi-tenant et isolation de l administration
- Base de gestion des tenants, organisations, departements et canaux de distribution
- Acces aux fournisseurs de modeles et gestion du routage
- Mesure de l utilisation des tokens et base de facturation
- Bases pour recharge, coupons, abonnements, factures, paiements et partage de revenus
- Console d administration par tenant et tableaux de bord commerciaux
